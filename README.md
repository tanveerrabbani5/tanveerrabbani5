## 🚀 Featured Projects

### 🔐 Secure AWS 3-Tier Infrastructure with Terraform

A production-style AWS infrastructure project built using **Terraform (Infrastructure as Code)** to provision, configure, and manage AWS resources. The infrastructure was successfully deployed and tested.

#### Key Areas

- AWS VPC architecture with six subnets across two Availability Zones
- Public and private subnet configuration
- Internet Gateway and NAT Gateway
- Application Load Balancer (ALB)
- Private Ubuntu EC2 instance without a public IP address
- Amazon RDS for MySQL in private subnets
- IAM roles and instance profiles
- Security Groups for ALB, application, and database tiers
- Terraform modules for reusable infrastructure
- Nginx installation and web page deployment using EC2 user data
- ALB target group health checks
- RDS storage encryption and automated backups

#### Testing & Results

- ✅ Terraform formatting and validation completed successfully
- ✅ AWS infrastructure provisioned using Terraform
- ✅ ALB target group verified with a healthy EC2 target
- ✅ Web application accessed successfully through the ALB DNS endpoint
- ✅ RDS database verified as available and not publicly accessible
- ✅ Project documentation and deployment screenshots added to GitHub

**Technologies:** `AWS` `Terraform` `VPC` `EC2` `ALB` `RDS MySQL` `IAM` `Ubuntu` `Nginx` `Git` `GitHub`

**Status:** ✅ Completed & Tested

🔗 **[View Project on GitHub](https://github.com/tanveerrabbani5/aws-terraform-3tier-infrastructure)**

> **Note:** This is a production-style learning project, not a fully production-ready or highly available system. The tested setup used one application EC2 instance, a single-AZ RDS instance, and HTTP access through the ALB. AWS resources may be destroyed after testing to avoid ongoing charges.
